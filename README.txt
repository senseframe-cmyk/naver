Montalk — UX Onboarding prototype

실행: index.html을 Chrome 또는 Safari에서 열거나 정적 웹 서버로 폴더 전체를 제공하세요.
프로토타입: Enter → 알 깨우기 → 인사 → 이름 → 목표 → 수준 → 첫 영어 발화 → 성취 → 홈.

Document: 8장. 기존 양식 문구는 보존하고 새 작성 내용은 짙은 녹색(#215e50)으로 구분했습니다.
1 표지 / 2 사용자와 문제 / 3 핵심 흐름 / 4 핵심 화면 5개 / 5 상태별 화면 5개 / 6 돌아보기 / 7 연구 출처와 한계 / 8 검증 계획과 추가 아이디어.

문서 원본: index.html의 docPages. docs/document-*.svg는 동일한 벡터 본문의 보관본입니다.
4·5장 화면: document-content.js가 index.html?docPreview=단계 번호로 실제 앱 렌더러를 불러옵니다.
프로토타입의 문구·이미지·레이아웃은 같은 코드에서 제공되어 별도 캡처를 고칠 필요가 없습니다.
미리보기는 애니메이션과 마이크 동작을 정지하고 전체 화면을 표시합니다. 저장된 사용자 정보도 변경하지 않습니다.
새 단계를 추가하거나 문서에서 대표할 상태를 바꿀 때는 document-content.js의 sheets 구성을 조정하세요.

7장에 공개 연구의 원문 링크가 있습니다. 사용자 집단과 언어가 다른 연구는 적용 한계를 명시했습니다.
사용자 페르소나·캐릭터 효과·완료율 개선은 검증 전 가설이며, 인터뷰 및 사용성 테스트를 진행한 것으로 쓰지 않았습니다.
브라우저 음성 인식/합성은 권한과 지원 여부에 따라 다르게 동작합니다.
원본 문서 템플릿과 참고 PNG는 docs 폴더에 보존했습니다.
